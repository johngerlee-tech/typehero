## 🚀 本地執行方式

本專案為純純淨前端靜態架構，無須複雜建置流程：
1. 直接在瀏覽器中開啟 `index.html` 即可完整暢玩！
2. 或使用任何靜態本地伺服器（例如 VS Code Live Server 或 Python）：
   ```bash
   python -m http.server 8080
   ```
   在瀏覽器打開 `http://localhost:8080`。

## 🌐 部署至 GitHub Pages 教學

1. 在 GitHub 上建立一個新的公開儲存庫（Repository），例如 `type-hero`。
2. 將本專案資料夾內的檔案上傳至該儲存庫：
   ```bash
   git init
   git add .
   git commit -m "Initial commit for TypeHero"
   git branch -M main
   git remote add origin https://github.com/<您的使用者名稱>/type-hero.git
   git push -u origin main
   ```
3. 進入 GitHub 儲存庫的 **Settings** -> **Pages**。
4. 在 **Build and deployment** 的 Branch 選擇 `main` 與 `/ (root)`，點擊 **Save**。
5. 稍等 1~2 分鐘，即可獲得免費的線上專屬網址：`https://<您的使用者名稱>.github.io/type-hero/`！

## ☁️ 連接 Firebase 雲端資料庫教學

若欲啟用跨電腦全校即時排行榜，可免費建立 Firebase 專案：
1. 前往 [Firebase Console](https://console.firebase.google.com/) 並新增專案。
2. 在「建構」中開啟 **Cloud Firestore**，並建立資料庫（測試模式啟動）。
3. 在專案設定中新增「網路應用程式 (Web App)」，複製其中的 `firebaseConfig` 物件。
4. 在 `js/firebase-config.js` 中填入您的設定，或直接在遊戲網頁中設定，全校學生即可享有即時成績雲端漫遊！
